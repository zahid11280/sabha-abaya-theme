# Sabha Abaya Co. – Shopify Theme Sections

Custom Shopify sections for the Sabha Abaya Co. storefront (header to footer).

## Structure

```
sections/
  header-group.json          Header group (auto-generated by the theme editor)
  sabha-header.liquid        Announcement bar, header, search, mobile menu, cart drawer
  sabha-hero-banner.liquid   Hero banner
  sabha-promise-section.liquid  3-item promise strip
  sabha-product-grid.liquid  "Just arrived" product grid
  sabha-story.liquid         Story / about block
  sabha-signatures.liquid    "Sabha signatures" product grid
  sabha-footer.liquid        Footer + newsletter
snippets/
  sabha-vars.liquid          Shared CSS variables (used by the header)
  sabha-card.liquid          Product card (used by product grid + signatures)
templates/
  index.json                 Homepage layout (auto-generated by the theme editor)
```

## Use

Copy the files into the matching folders of your theme (or push with Shopify CLI / GitHub integration), then add the sections from the theme editor.

## Notes

- File names in `sections/` must match the `"type"` values in `templates/index.json` (e.g. `sabha-hero-banner`, `sabha-promise-section`).
- `index.json` also references the base theme's `slider` section (currently disabled); that file is not part of this repo.
- `sabha-header.liquid` is used from `sections/header-group.json`, not from `index.json`.
- `header-group.json` also references the base theme's `annoucement` and `header` sections, plus a disabled `sabha-announcement-bar` section that is not part of this repo.
- `templates/index.json` and `sections/header-group.json` are rewritten by the Shopify theme editor, so re-sync it before committing.
